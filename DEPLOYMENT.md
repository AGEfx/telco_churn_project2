**Deployment Guide (Инструкция по развёртыванию)**

Объект: Веб-приложение для предсказания оттока клиентов (Telco Customer Churn).

Стек технологий: Python, Streamlit, Pandas, Scikit-learn / XGBoost, Docker.

Приложение поддерживает два сценария развертывания. Выберите наиболее подходящий в зависимости от вашей инфраструктуры.

**Вариант 1. Локальный запуск через виртуальное окружение (Python)**
Данный метод подходит для локальной разработки и тестирования.
Требования: Установленный Python (версии 3.9 — 3.11) и утилита Git.

Клонирование репозитория:
Склонируйте исходный код проекта на локальный ПК и перейдите в рабочую директорию:

Bash
git clone https://github.com/AGEfx/telco_churn_project2.git
cd telco_churn_project2

2. **Создание и активация виртуального окружения (опционально, но рекомендуется):**
   ```bash
   python -m venv venv
   # Для Windows:
   venv\Scripts\activate
   # Для macOS/Linux:
   source venv/bin/activate
Установка зависимостей:
Установите все необходимые пакеты из конфигурационного файла:

pip install -r requirements.txt


4. **Запуск приложения:**
   Инициируйте запуск встроенного сервера Streamlit:
   ```bash
streamlit run app.py
Доступ к интерфейсу:
После успешного запуска приложение будет автоматически открыто в браузере по умолчанию. Ручная ссылка для доступа: http://localhost:8501

Вариант 2. Развертывание в изолированном контейнере (Docker)
Рекомендуемый метод для продуктовой среды (Production), так как он гарантирует идентичность окружения на любых операционных системах.
Требования: Установленный и запущенный сервис Docker Engine (или Docker Desktop).

Клонирование репозитория:

Bash
git clone https://github.com/ВАШ_ЛОГИН/telco_churn_project2.git
cd telco_churn_project2

2. **Сборка Docker-образа:**
   Соберите образ на основе предоставленного `Dockerfile`. Команда скачает нужную версию базового образа ОС и установит все зависимости:
   ```bash
docker build -t telco-churn-app .
Запуск контейнера:
Запустите изолированный контейнер в фоновом режиме, пробросив стандартный порт Streamlit (8501) на хост-машину:

Bash
docker run -d -p 8501:8501 --name churn-app-container telco-churn-app

4. **Доступ к интерфейсу:**
   Откройте любой веб-браузер и перейдите по адресу: `http://localhost:8501`

*(Примечание: для остановки контейнера используйте команду `docker stop churn-app-container`)*.
